How to run the program in API:
1. Run the following in the terminal
- dotnet restore API/MonteCarloApi.csproj
- dotnet build API/MonteCarloApi.csproj
- dotnet run --project API/MonteCarloApi.csproj
2. Navigate to the following browser:
- http://localhost:5xxx/swagger
- replace the 'xxx' with the numbers from the output in the terminal
3. Click 'Try it out'
4. Input option parameters
5. Click 'Execute
